# Video Studio

A local video-finishing app for Windows: trim and assemble clips, add
captions with word-level timing, burn them on, add background music, and
render upload-ready files. Everything runs on your own machine.

This repository exists to **distribute the app and its updates**. Each
release carries:

- `VideoStudio-<version>.zip` - the program (about 200 KB)
- `update.json` - what the newest version is

An installed copy checks the latest release on startup and offers a
one-click update. It only ever replaces program files; your videos,
projects and settings are never touched.
